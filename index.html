Настройка Claude Code

Как Claude работает с проектом

Простым языком о том, как Claude настроен в этом репозитории: что он знает ещё до начала работы, какими инструментами пользуется и как доводит задачу из Linear до merge request, готового к ревью.

Общая картина

Каждая сессия Claude начинается с одних и тех же знаний о проекте. Сверх этого он может подгрузить дополнительные инструкции под конкретный вид работы и обращаться к внешним сервисам, таким как Linear и Nightwatch.

Что Claude знает и чем пользуется

Общие правила

Инструкции для всего проекта, которые читает каждая сессия: стиль сообщений коммитов, соглашения по тестам, стандарты PHP, запрещённые команды для базы данных и устройство локального окружения.

Правила для папок

Соглашения, которые касаются только определённых файлов: моделей, form request'ов, Vue-компонентов. Индекс подсказывает Claude, какой файл правил прочитать для файла, который он собирается менять.

Подключённые сервисы

Laravel Boost позволяет искать по документации, смотреть базу данных и читать логи. Nightwatch даёт ошибки с продакшена. В Linear и Scrumpy лежат задачи. Через Chrome Claude пользуется приложением как человек.

Помощники

Два специализированных ассистента, которым Claude может передать работу: один делает ревью кода, другой ищет причины ошибок и падающих тестов.

.claude/agents

От задачи до merge request

Вы даёте Claude номер задачи из Linear (например, F-1234) или номер ошибки из Nightwatch (например, #123). Claude создаёт под неё отдельную копию проекта, работает в ней и возвращается либо с черновым merge request, либо с понятным объяснением, на чём он застрял.

  1. Отдельное рабочее место

    Каждая задача получает свою копию проекта со своей веткой, базой данных и адресом, поэтому над несколькими задачами можно работать одновременно, и они не мешают друг другу.

  2. Разобраться в задаче

    Claude читает задачу или отчёт об ошибке. Если критерии приёмки размыты, он составляет их сам и согласует с вами до того, как писать код. Баг он сначала пытается воспроизвести в браузере.

  3. Минимальное рабочее изменение

    Claude повторяет устоявшиеся подходы из соседних файлов, следует правилам для затронутых папок и добавляет тесты на новое поведение. Никакого постороннего рефакторинга.

  4. Проверить работу

    Код форматируется автоматически, запускаются тесты, которые покрывают изменение. Изменения во фронтенде дополнительно проверяются в Chrome и записываются в короткий GIF.

  5. Взгляд со стороны

    Отдельный Claude, который не писал этот код и не может его менять, сверяет его с критериями приёмки и правилами проекта. Claude исправляет найденное, но не больше двух раз.

  6. Передать дальше

    Claude делает коммит, пишет короткий отчёт (сколько заняло времени, сколько раз понадобилась ваша помощь, что мешало) и открывает черновой merge request. Merge и деплой всегда остаются за человеком.

Проверка страницы в браузере

В отдельной копии проекта Claude запускает приложение только на время проверки и потом его останавливает.

Чего Claude делать нельзя

  • Стирать или сбрасывать базу данных для разработки. Пересоздавать можно только тестовую базу.
  • Пушить в master или трогать ветку acceptance.
  • Мержить merge request'ы или что-либо деплоить.
  • Ослаблять, пропускать или удалять тесты, чтобы проверки прошли.
  • Добавлять в коммит всё сразу. Файлы добавляются по имени, чтобы ничего лишнего не попало.

Как процесс улучшается

Каждый отчёт о запуске заканчивается заметками о том, что усложнило работу: размытая задача, отсутствующее правило, слабые тесты, сломанное окружение. По этим заметкам улучшаются скиллы, общие правила и правила для папок, чтобы следующий запуск прошёл легче.

Словарь

Worktree
Вторая рабочая копия репозитория в своей ветке. Здесь у каждой есть ещё и своя база данных и порт.
Herdr
Терминальный инструмент, который создаёт worktree и запускает в каждом сессию Claude.
Скилл
Письменная инструкция, которую Claude загружает под конкретную задачу, например выполнение задачи или проверку страницы.
MCP-сервер
Подключение, через которое Claude получает доступ к внешней системе, например к Linear или к базе данных приложения.
Laravel Boost
Пакет для Laravel, который генерирует инструкции для Claude и подключает его к приложению.
Отчёт о запуске
Короткий лог, который коммитится с каждым запуском и хранится в .ai/factory/runs.
